# Matemáticas discretas

La matemática de lo que se cuenta y se conecta: inducción, combinatoria, recurrencias y funciones generadoras, relaciones y órdenes, teoría de grafos, teoría de números y probabilidad discreta, sobre la red de una ciudad.

**Ver en línea:** https://aaramirez.github.io/matematicas-discretas/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
